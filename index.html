免费在线网站检测工具

一站式网站诊断平台，提供 HTTP 状态、DNS 解析、SSL 证书、响应时间和 HTTP Headers 检测，帮助你快速排查网站问题。

HTTP 状态检测

检测网站的 HTTP 状态码，了解网站是否正常在线访问，快速排查 404、500 等错误。

DNS 查询

查询域名的 A、CNAME、MX、NS、TXT 等各种 DNS 记录，支持多类型解析查询。

SSL 证书检测

检测网站 HTTPS 证书状态，查看证书颁发机构、有效期和到期时间，确保网站安全。

响应时间检测

测量网站的加载响应时间，评估网站性能，帮助你优化用户体验。

HTTP Headers 检测

查看网站的 HTTP 响应头信息，检测安全头配置（CSP、HSTS、X-Frame-Options 等）。

工具使用指南

使用 SiteCheck 非常简单，只需三步即可完成网站检测：

  1. 选择工具：根据需求点击上方对应的工具卡片，进入相应的检测页面。
  2. 输入域名：在输入框中填写要检测的网站域名（例如 example.com），无需添加 http:// 前缀。
  3. 查看结果：点击检测按钮，稍等片刻即可获得详细报告，包含状态码、解析记录、证书信息等。

建议定期对重要网站进行检测，及时发现潜在风险。如需了解各工具的详细用法与原理解析，可参阅我们的技术博客文章。
